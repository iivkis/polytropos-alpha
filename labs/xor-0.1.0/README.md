# XOR laboratory 0.1.0

This is a separate VeriNeural consumer, not a built-in XOR primitive or a training framework.

A four-row Boolean truth table is evaluated by a fixed-weight 2 -> 2 -> 1
ReLU MLP, composed using the public NeuralModule and NeuralGraph API:

    Input [4,2]
      -> MatMul([2,2]) -> BiasAdd([2]) -> ReLU
      -> MatMul([2,1]) -> BiasAdd([1]) -> ReLU
      -> Output [4,1]

For each input row, the hidden pre-activations are (x+y, x+y-1).
The output is ReLU(ReLU(x+y) - 2*ReLU(x+y-1)), which equals Boolean XOR
for x,y in {0,1}. All concrete inputs, weights and intermediates are tiny
integers exactly representable in binary32.

## Run (from the workspace root, inside nix develop)

    task test-lab-xor
    task lab-xor
    task verify-lab-xor

Optional custom artifact root (relative to this lab package, or an absolute
path) works for both commands:

    task lab-xor -- --artifact-root evidence
    task verify-lab-xor -- --artifact-root evidence

The CPU-only tests check composition, global proof generation, GPU plan
generation and rejection of malformed shape and nonfinite parameters. The run
command generates exactly one canonical architecture_global_nonnegative Lean
proof, audits its axioms, lowers the same Semantic IR to LLVM NVPTX/PTX, then
executes it using NVIDIA CUDA Graph and compares all four FP32 outputs bitwise
with an independent Boolean XOR oracle. It exports that same Semantic IR as
one DOT/PNG architecture snapshot.

Artifacts are automatically generated by task lab-xor in the package root
(labs/xor-0.1.0/) by default. There is one artifact set only:
semantic.ir, architecture.dot, architecture.png, architecture.lean,
SHA256SUMS, input/parameter/output bits, report.txt, and GPU execution
evidence under gpu/. No duplicate auto-build bundle is produced. The offline
verify command reconstructs the current graph/proof/translation plan and
checks that same persisted artifact set plus its SHA-256 manifest.
It does not execute CUDA again. Pin the printed manifest hash separately
if provenance across machines matters.

## Guarantee boundary

Lean proves only the requested ideal-Int elementwise nonnegativity theorem,
not the complete XOR truth table. Four concrete truth-table cases are
independently checked against NVIDIA GPU output. CUDA driver, JIT, SASS,
strict machine FP32 equivalence and training/convergence are not proven.
There is no optimizer, backpropagation or weight training in this lab.
