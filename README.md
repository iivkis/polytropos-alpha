# polytropos-alpha

Исследовательский проект **VeriNeural**: импортируемая Rust-библиотека, компилятор и система формальной верификации нейросетевых вычислений и архитектур.

## Состояние

**Этап 1/10: инициализация.** Пока создан каркас. GPU-компиляция, Lean-доказательства, численная сертификация и нейросетевая архитектура **ещё не реализованы**.

- `crates/verineural/` — Rust-библиотека, не самостоятельное приложение.
- `Cargo.toml` — корневой Cargo workspace; в будущем он будет содержать и другие crates для компилятора, доказательств и нейросетевых модулей.
- `flake.nix` — среда Rust / LLVM / CUDA / Lean 4 / Task для Linux x86_64.
- `Taskfile.yml` — команды для локального разработчика.
- [SPEC.md](docs/verineural/SPEC.md) — полная **целевая** спецификация VeriNeural (без этапов и MVP).
- [ROADMAP.md](docs/verineural/ROADMAP.md) — 10 крупных последовательных этапов реализации.
- [agents.md](agents.md) — правила работы ИИ-агентов; [AGENTS.md](AGENTS.md) направляет к ним.

## Интеграция

На начальном этапе `verineural` подключается через Cargo workspace/path dependency. Нейросетевая архитектура будет реализована позже на Rust с использованием этой библиотеки, а не как часть текущего scaffold.

## Локальная разработка

```sh
nix develop
task --list
# Сборки и тесты выполняет пользователь локально:
task check
task test
```

Для GPU-исполнения нужен совместимый NVIDIA GPU и системный NVIDIA-драйвер, который devShell не устанавливает.

Наличие проекта, математических контрактов или файлов сертификатов само по себе не означает, что исполняемый GPU-код формально проверен.
