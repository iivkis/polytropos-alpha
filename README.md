# polytropos-alpha

Исследовательский проект нейросетевой архитектуры и формально проверяемого GPU-вычислительного слоя **VeriGPU**.

## Текущее состояние

**Этап 1/10: инициализация.** В репозитории пока есть только фундамент для разработки, без GPU-компилятора, доказательств и нейросетевой архитектуры.

- `crates/verigpu/` — импортируемая Rust-библиотека, не исполняемое приложение.
- `Cargo.toml` — корневой Rust workspace. Будущая нейросетевая архитектура подключит `verigpu` как зависимость.
- `flake.nix` — среда разработки Rust / LLVM / CUDA / Lean 4 / Task (Linux x86_64).
- `Taskfile.yml` — единая точка входа для локальных команд.

## Локальная разработка

```sh
nix develop
task --list
# Команды вроде task check, task test и task build запускает разработчик локально.
```

Для GPU-исполнения дополнительно нужны совместимый NVIDIA GPU и установленный **хостовый NVIDIA-драйвер** (он не поставляется через devShell).

Сертификация пока не реализована; наличие каркаса проекта не означает наличие проверенных доказательств.
